Merapi Sky Courier is an original offline flight game: fly a red courier plane over a Merapi-style volcanic ridge, through glowing rings, past rice terraces and a river town, and land on runway 09. Three missions, fuel and hull to manage, wind gusts, and a lit cockpit panel with altitude, speed and heading on the HUD.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome. No network request, no build step — `game/` is plain static files.

Controls: 1 / 2 / 3 pick a mission, ↑ / ↓ throttle, ← / → bank, SPACE climb, X descend, mouse steers gently, P pauses, R restarts.
